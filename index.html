Quick start

Your first frames,
about a minute of setup

No manual required — the whole loop is five screens deep. Here's the path from a fresh install to your first real statistics.

01

Add your league or tournament

Open the menu and create a league with your house's name — the bowling center, oil pattern, and lane details live here so you never re-type them. Tournaments work the same way: one parent, many dated events.

Where Menu → Leagues → +
02

Start tonight's event

One tap opens a dated event for today. League events inherit your center and pattern automatically and just ask for the lane pair — you're ready before the ball return warms up.

Where League → Start Event
03

Score as you bowl

Tap the pins left standing after each shot, or use the X, /, and – quick marks. Every shot autosaves instantly, games complete themselves, and Next Game keeps the set moving. Mis-tap? Any frame can be corrected later.

Where Event → Start Game 1
04

Add context when it matters

Pick the ball for each shot and, when you want the full picture, open Pro context to log your target line, speed, and shot quality. It's optional on every shot — a casual night stays casual.

Where Scoring → Pro context
05

Read the numbers

The event hub scores your night in nine metrics the moment you finish. Then Stats takes the long view — strike rate, spare conversion, and leave-by-leave weaknesses across every game you've ever saved.

Where Menu → Stats
Create → Bowl → Review. That's the whole loop.

No account to create, nothing to configure — the app is ready the moment it's installed.

Your data

Your game. Your device.
Nobody else's business.

StrikeIQ doesn't just promise privacy — it's built so the question never comes up.

The app never requests network access, so the operating system itself guarantees your bowling data can't be transmitted. No accounts, no ads, no analytics SDKs.

FAQ

Straight answers

Is StrikeIQ free?

Yes — free, with no ads, no subscriptions, and no in-app purchases.

Does it need internet or an account?

No. StrikeIQ works fully offline and doesn't even request the Android internet permission — the OS itself guarantees your data can't leave the device. No accounts, no cloud, no analytics.

Which phones does it run on?

Any Android phone on Android 8.0 (API 26) or newer. The app is portrait-first and tuned for one-handed use at the lanes, verified up to 200% font scale for accessibility.

Can I move my history to a new phone?

Yes, two ways: export a portable, checksum-verified backup file and import it anywhere, or let Android's device-to-device transfer and Auto Backup carry the database across automatically.

Does it handle 9-Pin No-Tap?

Yes — as an event-scoped scoring format, not a hack. Raw pinfall is preserved, no-tap strikes are marked distinctly, and your natural strike rate is reported separately so sport-shot stats stay honest.
